User Manual

  • Target: End users
  • Applet: Unity WebGL

This section describes how to use the application and explains all the parameters available for exploring surface approximation using Coons patches.

Scene Controls

  • Mouse: camera rotation
  • Scroll: zoom in/out
  • W A S D: horizontal movement
  • Q / E: vertical movement
  • C: toggle camera mode
  • ESC: return to UI mode

The application distinguishes between UI interaction mode and camera navigation mode, preventing input conflicts.

Reference Surface

The reference surface represents the original geometry that the system attempts to approximate. It is defined as a scalar function over a planar domain.

Available parameters

  • Surface Type: selects analytic or noise-based surface
  • Height Scale: controls vertical amplitude
  • Noise Scale: controls frequency/detail
  • Randomize: generates a new random configuration

More complex surfaces (higher frequency or amplitude) are generally harder to approximate with a limited number of patches.

Domain Subdivision

The domain is subdivided into a rectangular grid. Each cell corresponds to a Coons patch.

  • Grid Resolution X: number of divisions along X
  • Grid Resolution Z: number of divisions along Z

Increasing the grid resolution:

  • reduces patch size
  • improves approximation accuracy
  • increases computational cost

Coons Patches

Each grid cell is approximated using a bilinear Coons patch, constructed from the boundary curves sampled from the reference surface.

  • Patch Resolution: internal mesh density

This parameter affects only the visual smoothness of the rendered surface, not the mathematical definition of the patch.

Error Analysis

The application compares the approximated surface with the reference surface by evaluating the error at sampled points.

  • Mean Error: average deviation
  • Max Error: maximum deviation
  • RMSE: root mean square error
  • Sample Count: number of evaluated points

These metrics provide a quantitative evaluation of the approximation quality.

Heatmap

The approximation error is visualized through a color map applied to the surface.

  • Enable Heatmap: toggle visualization
  • Max Error Range: controls color normalization

Color encoding:

  • Blue → low error
  • Green → moderate error
  • Yellow → high error
  • Red → very high error

Regions with higher curvature tend to exhibit larger approximation errors.

Vertical Offset

The approximated surface can be vertically shifted to improve visual comparison with the reference surface.

  • Vertical Offset: separation between surfaces

This parameter does not affect the approximation itself, but improves readability by avoiding overlap.
